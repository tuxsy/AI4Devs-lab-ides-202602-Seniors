# Definición del modelo de datos

Lee la [historia de usuario](./user-story-md) que estamos desarrollando.

Define y documenta el modelo de datos en `./docs/data-model.md`. Crea un diagrama entidad/relación con mermaid sencillo, en el que muestres sólo los nombres de las tablas y sus relaciones. Luego crea tablas en Markdown con los atributos de cada tabla.
